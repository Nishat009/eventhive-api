# EventHive API

Event & Ticket Booking Platform — a modular REST API built with Node.js, TypeScript (strict), Express 5, and PostgreSQL (native `pg`, raw parameterized SQL).

> 🚧 Work in progress. Full documentation will be added as development continues.

## Setup

```bash
npm install
cp .env.example .env   # then fill in the values
npm run dev
```
